#### 💻 Technologies used

<List items={['ReactJs', 'Electron', 'Prop-types', 'Redux', 'Immutable', 'Mocha/Enzyme']} />

Ladbrokes and Coral were replacing the point of sale software used by staff in thousands of shops across the UK. I worked in an Agile Scrum team on the frontend of that desktop application.

#### What I did
- Built the interface of a large desktop app with React and Electron, using modern ES6, Redux and Immutable.
- Worked in a codebase with more than 10,000 unit tests, using Mocha and Enzyme.
- Worked with a backend made of Java and Node services on AWS and local C# services on the till itself.
- Released through Jenkins, which ran the tests and packaged the Electron releases from Git activity.

#### Skills I used
Large scale frontend architecture, state management, unit testing, Agile Scrum, and shipping desktop software through a CI pipeline.
