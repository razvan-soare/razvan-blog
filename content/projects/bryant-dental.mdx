Bryant Dental is a UK based maker and distributor of dentistry equipment, mostly dental loupes. This was the first project where I led the frontend, and it won recognition in the dental industry and in web design.

<VideoGifImg type="video" path="bryant-dental/video1.mp4"/>

#### What I did
- Was the Frontend Lead: I designed the architecture of the project and coordinated a team of 5 frontend developers over a year and a half.
- Built the animations, smooth transitions and custom interactions that show off the 3D renders and make the site feel premium.
- Integrated the site with the API and with Strapi, a headless CMS.
- Built the presentation layer with GatsbyJs for performance.

#### Skills I used
Technical leadership, project architecture, animation and motion design, performance work and headless CMS integration.
